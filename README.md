# Project Setup Instructions (Windows)

Follow these steps to set up and run the project on a **Windows** machine.

---

## ✅ 1. Download the Project

* Download and extract the project ZIP file from the GitHub repository.
* Open the extracted folder in **Visual Studio Code**.

---

## ✅ 2. Open the Terminal in VS Code

* Go to: **Terminal → New Terminal**

---

## ✅ 3. Navigate to the Project Directory

```bash
cd quizs_events-main
```

---

## ✅ 4. Create a Virtual Environment

```bash
python -m venv myenv
```

---

## ✅ 5. Activate the Virtual Environment

```bash
myenv\Scripts\activate
```

---

## ✅ 6. Install Project Dependencies

```bash
pip install -r requirements.txt
```

---

## ✅ 7. Change Directory to the Main App Folder

```bash
cd niral_aghara
```

---

## ✅ 8. Start the Development Server

```bash
python manage.py runserver
```

---

## ✅ 9. Open the Application in Your Browser

Open the following URL in your browser:

```
http://127.0.0.1:8000/
```

---

✅ Your application should now be running successfully!
